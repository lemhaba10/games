# Consignes pour le projet Godot Killers

- Ce dossier contient le projet moteur, le code, les scènes, les ressources et les réglages du jeu.
- Avant de modifier le jeu, lire et appliquer `../killers/AGENTS.md`, puis lire `../killers/GAME_DESIGN.md`, la référence de conception. Les propositions d'équilibrage ne sont pas toutes des règles confirmées.
- Conserver la documentation de conception dans `../killers`. Mettre à jour les décisions et le journal de conception après un choix explicite des créateurs.
- La racine Git est le dossier parent `games`. Ne pas créer de dépôt imbriqué et ne pas versionner le cache `.godot`.
- Le projet existant utilise Godot 4.7 et le rendu Compatibility. Ne pas le recréer ou le déplacer pour commencer le prototype.
